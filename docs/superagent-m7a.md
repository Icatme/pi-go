## 先核对 M4 / M6

M4 的 `background.Backend` 已规定稳定 ID、冲突拒绝、Stop tombstone、实际退出
与取消区分；Start 出错不代表未执行，协调器重启只能查询原 ID。M6 的共享日志
租约只保护协调器提交，不能撤销已经发出的设备命令。因此本次不改主调度器或
共享日志格式，只增加可选 `superagent/device` 后端和设备侧持久 admission fence。

范围刻意收小：宿主显式注册并选择一台固定设备；提供轻量可嵌入 HTTP handler、
客户端后台适配器、经过认证的能力/存活查询。没有自动设备发现、智能调度、
真实设备接入、账号登录、认证服务、SSH、远程 shell、持久访问凭据或额外计费。
离线状态由已绑定设备与 unknown/review 表达，不自动重发或改派。

## 已实现的边界

- 固定 domain/device/workspace/policy/tool allowlist 计算稳定 Scope，保存在现有
  M4 操作记录；改变设备或权限配置不会静默改派旧操作。原生工具继续自行执行
  OS/网络/凭证和效果前权限检查；workspace 字符串不是沙箱。
- 每条命令在同一锁内做宿主当前权限校验、持久 epoch fencing、操作准入。
  当前权限回调必须校验有效所有权，不只信任客户端声明或最高见过的 epoch。
  新所有者仍可查询/停止旧 ID；旧所有者不能再查询、启动或停止。
- Start 先持久化身份摘要，再调用后端，再持久化接收确认；同 ID 不再物理启动。
  Stop 先落停止意图，随后请求取消，未知 ID 保留 tombstone。断线只查原 ID。
- 设备重启把原 running 记录持久改为 unknown，不重放 Start。已知退出可从
  注册表恢复；丢失后端证据保持待核实。Create 只用于明确新建；Open 缺文件拒绝，
  不把丢失注册表当成一台全新设备。
- 原始参数只瞬时用于执行，设备注册表保留 digest；原始结果、错误、panic 与
  子回执字符串不出设备。对外只给退出/失败/已知提交事实，保留原操作/调用 ID。
  设备私有回执指纹用于防止回执消失、身份变化或状态回退被误判为实际退出。

完整 API、宿主认证责任、限额和部署限制见
[设备协议说明](../superagent/device/README.md)。

## 测试与独立审查

测试先于实现建立失败基线。验收包含：

- 两个模拟设备只接受各自授权 Scope；并发重复启动仅执行一次；冲突 ID、工具
  越权、绑定变更、过期权限、旧 epoch 和缺失/损坏状态均被拒绝。
- 两个独立子进程通过真实 loopback HTTP 编解码；接令前断线保持 unknown，提交
  效果后丢回执可查询确认；提交后、接收确认前进程退出，重开不重复执行。
- 保留停止意图与迟到提交；在 reservation、接收确认、观察结果写入失败边界
  保持不确定和禁止继续入账；启动注册表不自动修复断尾。
- 原生 Local + Pi Worker + M6 sharedsqlite 完整集成：后台屏障未释放前，同一
  Worker 处理新输入；协调器换 epoch 重开，离线 unknown 保留审核与配额；
  原 ID 退出后完成事件只投回原调用一次，原生启动调用仍只有一个工具响应。
- 设备凭证 canary 不进入 wire、模型请求、Worker 快照、回复、协调器日志或
  设备注册表；错误、panic、任意子回执元数据不外泄；不跟随重定向或自动重试。
- 独审发现并修复：聚合回执漏检底层回执回退、不可能的首次终态重放、以及
  重开后仅内存改 unknown 导致下一次 Stop 日志不可重放。补齐对应回归。

最终验证命令与精确树记录在 PR。PowerShell 在该远程容器不可用，使用 POSIX
shell 与 Linux amd64 Go 1.26.10。没有真实设备、用户本机、模型/provider 调用、
新增持久凭据、Codex/额外计费任务、手动 CI、合并或部署。

## 不作出的保证

这不是完整 M7：自动设备选择/等待重连调度、设备配对认证、远程产物/原始结果
传输、耐久进程执行器、跨设备全局配额、日志压缩和生产运行均待后续。
设备资源/后代进程生命周期由后端负责；替换后端不是旧执行体退出的证据。
M4 保存其会话内配额，本协议不提供跨独立协调器日志的耐久设备全局配额。

设备注册表依赖宿主可信私有本地目录及可靠文件锁；创建时不 fsync 父目录，
因此仅验证进程故障，不声称断电耐久、文件系统损坏防护或恰好一次外部效果。
真实 TLS/认证、真实设备网络分区、Windows/macOS 运行时尚未验证。
