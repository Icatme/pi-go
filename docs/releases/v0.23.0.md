# v0.23.0

SuperAgent adds optional host-owned main-context compaction and durable,
read-only intervention follow-up evidence. Session journal reads and strict
replay avoid redundant JSON copying without changing the storage contract.

- `PiMainRouter`, `PiMainBatchRouter`, `PiMainHistoryRouter` and
  `PiMainBatchHistoryRouter` accept an optional `MainContextCompactor`. The
  host chooses and authorizes the summarizer. No summarizer or extra model
  request is enabled by default. Full requests remain bounded, complete
  recent turns are retained, and summaries are stored as untrusted history.
- Watchdog patrols can record one-shot evidence about completed interventions
  and expose it through `WatchdogFollowupsSince`. This observes committed
  coordinator facts without another backend probe, recovery action or external
  notification. Hosts retain consumption cursors and delivery authorization.
- Validated custom/lane journal reads use detached copies instead of repeated
  whole-log JSON encoding. Strict replay retains one validated normalization
  rather than normalizing the same item twice. Ordinary-message fallback,
  validation, ownership isolation and persistence boundaries remain intact.
- Offline journal-growth and asynchronous four-strategy comparison fixtures
  make replay cost and protocol accounting reproducible. They do not establish
  production performance, model quality, token cost or monetary savings.

## Upgrade and rollback

The four main-router constructors retain ordinary two-argument calls, but their
function types are now variadic. Callers storing a constructor in an exact
two-argument function variable must wrap it in a two-argument closure.

Context budgets now include the injected system message and history-tool
declarations and are checked at the actual model-request boundary. Budgets that
previously relied on undercounting may need to be increased.

Watchdog checks retain the previous reader contract until the first follow-up
evidence is committed. That first evidence upgrades the coordinator record
contract; older readers then fail closed, including after later empty checks.
Plan rollback around this one-way boundary before enabling that feature on
durable journals. No database schema or session wire-format change is required.

Main-context compaction reduces model input, not journal size. Full history is
retained; these changes do not provide bounded storage, checkpoints, deletion
or privacy erasure. PostgreSQL and other shared backends remain host-owned.
