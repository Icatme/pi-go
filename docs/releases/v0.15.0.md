Command Code's new model catalog and native protocols, reliable reasoning replay, and GPT-6 Luna image preparation.

## Changes

- Refresh Command Code's public catalog to 89 chat models, including Claude Haiku 5.5, GPT-6 Luna, Qwen 3.8 Omni Flash, DeepSeek V4.1, and Gemini 4 Argon. Update advertised image/reasoning capabilities, context and output limits, estimated prices and pricing tiers.
- Discover and cache native Messages, Responses and Chat Completions support from advertised endpoints. Preserve incremental reasoning, tool calls, tool results and native protocol identity during replay. Only an explicit HTTP 403 `upgrade_required` selects the Go-plan generate route.
- Preserve Claude's signed thinking blocks when visible thinking text is empty. Keep signatures isolated by model, provider and protocol. Clamp generate reasoning efforts to supported levels, including Qwen 3.8 `high` to `xhigh`.
- Prepare Command Code GPT-6 Luna PNG inputs as JPEG before sending, addressing the upstream PNG recognition defect observed in live validation. Cover both user and tool-result images without modifying caller history.
- Add model/request sampling parameters and thinking-level-specific overrides for OpenAI Completions and Responses. Preserve explicit zero/null overrides, reject protocol controls in sampling maps and validate the final merged sampling values.
- Allow case-insensitive Codex `originator` and `User-Agent` overrides on SSE and WebSocket requests. WebSocket reuse now respects the effective identity headers; authorization remains credential-derived.

## Upgrade notes

- Luna PNG conversion is lossy: JPEG quality 95, unchanged dimensions, and a white background for transparency. Local conversion limits are 32 MiB of PNG data, 64 Mi pixels and 65535 pixels per side. Malformed or oversized PNGs fail before HTTP. Other models and image formats are unchanged.
- A reasoning response can contain an opaque signature or encrypted block without visible reasoning text. The adapter retains these blocks for supported native replay; it does not invent text deltas.
- Command Code availability depends on the credential's plan. The catalog and estimated prices are snapshots, not an entitlement or billing guarantee. Use `COMMAND_CODE_API_KEY`, explicit request credentials, or the documented auth configuration.
- Normalized Responses reasoning options retain the logical pi thinking level until wire serialization. Sampling maps apply only to OpenAI Completions and Responses; protocol fields belong in their dedicated options.
- No storage migration or third-party dependency update. Go 1.26.2 or newer is required.

## Validation and downloads

The implementation passed root and example package tests, vet, builds and focused race tests. GOAT live calls verified reasoning, tool call/result replay and image input with Claude Haiku 5.5, GPT-6 Luna and Qwen 3.8 Omni Flash; DeepSeek V4.1 Flash also passed native capability checks. Luna's original PNG fixture passes after automatic JPEG preparation. Claude opaque signatures and Luna encrypted reasoning were checked in real replay payloads. These are bounded synthetic probes, not exhaustive acceptance of every catalog model.

Publication requires the exact release commit to pass the existing six-job CI workflow. Five CGO-disabled CLI archives cover Windows amd64, Linux amd64/arm64 and macOS amd64/arm64. Packaging verifies embedded source revisions and clean-tree flags, Unix executable modes, the Windows CLI banner and downloaded SHA-256 checksums.
