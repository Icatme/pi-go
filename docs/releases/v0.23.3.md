# pi-go v0.23.3

OpenAI Responses tool continuations now preserve an empty `summary: []` on reasoning items captured from incremental events and terminal responses. Replaying previously saved reasoning items also restores this required field when it is missing. Existing summaries and encrypted reasoning content are preserved.

The fix was checked with two-round OpenAI and Codex replay fixtures, the `pkg/pigo` package tests, focused race tests and `go vet`.
