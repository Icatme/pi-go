# v0.23.2

This release includes the provider, agent, session, MCP and Code Mode fixes
merged in #228-262 and the reviewed #263-298 integration delivered by #299.

- Preserve endpoint query bytes and escaped paths in the affected Chat,
  Responses, Anthropic/Kimi, Google, DeepSeek and CommandCode Generate paths.
  Correct OpenCode Go protocol endpoints. Library-owned provider HTTP clients
  restrict redirects to the original origin; CLI OAuth token exchanges reject
  redirects. Bound credential reads to regular files and close Codex callback
  connections after the graceful shutdown deadline.
- Reject invalid token usage and checked-arithmetic overflow before mutating
  usage snapshots. Correct xAI reasoning accounting, context-limit detection,
  ZAI periodic-quota handling, blocked/content-filter outcomes and missing
  terminal reasons. Preserve useful native stop, model, cache and nested Codex
  WebSocket error diagnostics.
- Preserve Anthropic initial text/thinking, signed Chat reasoning boundaries,
  DeepSeek reasoning replay and Mistral nested thinking. Retain native Responses
  phases and uniquely matched terminal ciphertext; keep generated message IDs
  distinct and disambiguate eligible completed foreign tool-call pairs.
  Reject conflicting, incomplete and empty terminal tool-call batches.
- Validate integer tool arguments without numeric rounding and preserve explicit
  null in nullable unions. Keep failed-generation, unexecuted tool results in
  audit history while excluding eligible marked results from built-in model
  replay. Release Agent run ownership when host listeners panic, preserving
  already finalized root results in the explicitly sequential facade.
- Support CR-only SSE framing in providers and MCP, preserve quoted OAuth
  challenge boundaries, and clean up scoped Codex connections. Code Mode search
  prioritizes exact authorized tool names and documents asynchronous discovery.
- Add explicit opt-ins for HTTP request-body byte preflight, Google function
  response images and JSON Schema parameters, top-level Responses tool
  declarations, retained-thinking context projection and Code Mode search
  description budgets. The existing Anthropic long-cache capability flag now
  controls extended TTL when long caching is requested. The low-level
  `HTTPStreamClient` can opt into bounded `Retry-After` waits.

## Upgrade notes

Default provider HTTP redirects now require the same scheme, hostname and
effective port as the initial request. Configure the final endpoint directly,
or supply an explicit client with the host's chosen redirect policy. Explicit
clients and WebSocket dialers keep their existing contracts. CLI OAuth token
exchange redirects are rejected separately. See [redirect policy](../provider-default-redirects.md).

Malformed terminal tool calls, invalid usage and incomplete streams now surface
errors where affected adapters previously accepted incomplete data. Error text
also retains more native diagnostics; callers matching strings should review
their classifiers. No general retry or automatic recovery policy is introduced.

New compatibility options remain host-selected. Google options do not activate
catalog capabilities; verify endpoint support before enabling them. Explicit
Anthropic long caching can incur extended-cache charges. `Retry-After` handling
is confined to the exported low-level client and is not automatically enabled
by `Stream`, `StreamSimple` or the agent.

The retained-thinking projection changes only the requested model-facing view,
not stored history. Failed-generation provenance does not repair old unmarked
records or custom serializers. Listener-panic snapshots can still contain
unfinished calls and are not a safe-resume guarantee. New public struct fields
may require callers using unkeyed literals to update them.

Requires Go 1.26.2 or newer. No third-party dependencies changed since v0.23.1.

## Validation and publication

The merged changes include offline regression coverage; their individual review,
test and platform results are recorded in the shared worklog. Release preparation
checks version references, read-only root/examples module graphs and diff hygiene.
It does not repeat full tests or race suites and does not perform live-provider
or UI acceptance testing.

Published as an annotated source tag and GitHub Release, without uploaded
packages or compiled binaries. No CI dispatch, deployment or downstream
dependency update is included.

```sh
go get github.com/Icatme/pi-go@v0.23.2
go install github.com/Icatme/pi-go/cmd/pi-superagent@v0.23.2
```
