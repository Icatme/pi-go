# v0.18.0

## Kiro adapters for Go applications

Register an adapter for buffered responses, incremental text, or incremental text
with tool calls. Applications supply the HTTP executor and scoped credentials.
Tool calls become available for authorization after the complete response validates.
Applications can also fetch a scoped model catalog and explicitly refresh IDC or
desktop credentials. See the [provider guide](../providers.md#kiro-for-go-applications).

Both stream entry points validate the original history before conversion. This
preserves pointer-valued text blocks and rejects malformed history before sending
credentials. Agent records Kiro context usage only on successful completion.

## Agent and Codemode fixes

- Chat preserves a final-only answer after an earlier tool turn emitted text deltas.
- Turn loops distinguish current model failures from errors in replayed history.
  Reflection preserves typed terminal causes, and terminal model errors suppress
  pending tool execution.
- Completed runs release their invocation contexts. During a run,
  `TryClearMessages`, `TryReplaceMessages` and `TrySetSessionID` return
  `ErrAlreadyRunning`. The existing void methods ignore concurrent changes.
- Invocation resource keys containing incomparable values are rejected before
  resource creation. Codemode rejects JavaScript properties that JSON conversion
  would silently discard when passing values to tools, output or storage. Copying
  a valid JSON value no longer invokes inherited descriptor getters.

## Upgrade notes

`agent.AgentEvent` gains a `ModelResponse` field. Switch positional literals to
named fields. Custom runners that emit model-generated message events should
set this field so the turn loop can recognize a message-only terminal failure.

Stream entry points resolve the API module before preparing the conversation.
A lazy module's factory can therefore run on a call whose context validation
subsequently fails.

Agent snapshots now encode a nonnil empty `ToolCall.ParsedArgs` as `{}`, preserving
an intentional empty edit across restore. Missing historical edits cannot be
recovered from old snapshots. The seven-field positional literal remains valid.
Code that directly assigns a ToolCall to an anonymous struct with the old JSON tag
must use an explicit conversion or the exported type. See the
[migration guide](../kiro-agent-authored-compatibility.md).

Builds require Go 1.26.2 or newer.

```sh
go get github.com/Icatme/pi-go@v0.18.0
go install github.com/Icatme/pi-go/cmd/pigo@v0.18.0
```
