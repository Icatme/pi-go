# v0.23.1

This patch release includes the reviewed provider and runtime fixes merged in
#223-227, plus the host-authorized task controls merged in #198-199.

- Preserve cancellation and deadline causes while reading provider responses,
  including non-success Mistral and DeepSeek bodies. Supported adapters retain
  actual HTTP error statuses through `ProviderHTTPStatusOf`; a status does not
  authorize retry, and coverage is not universal across providers.
- Preserve Google thought signatures, including signed empty and absent-text
  parts, through message conversion, persistence and replay. Correct compatible
  endpoint instruction-role selection, content-array handling, gateway routing,
  DashScope throttling and OpenCode Kimi thinking behavior. Anthropic fallback
  no longer restarts a response after observable output.
- Add opt-in `ApplyImageBudget`: the host supplies the image limit and protected
  history boundary. Only eligible old tool images receive explicit omission
  markers; protected overflow fails without partial output. No provider limit
  or automatic image pruning is enabled by default.
- Correct queue-hook cancellation and declared-tool search hints, preserve
  Code Mode error output, and reduce redundant session/compaction copying while
  retaining validation and ownership isolation. Regression guards cover
  Anthropic root tool schemas and local Code Mode bindings. Execution-tool
  documentation clarifies ordered Agent batches and Code Mode propagation.
- Expose explicit host choices for MCP child environment inheritance and
  unauthenticated compatible completion endpoints. Defaults retain environment
  inheritance and credential requirements.
- Extend SuperAgent assessment with optional `steer`, `result`, `list` and
  `stop` actions. Hosts offer capabilities, revalidate targets and execute the
  action; classification alone does not deliver, redirect or cancel work.

## Upgrade notes

Unknown compatible endpoints now use the system instruction role by default;
set `SupportsDeveloperRole` explicitly when the endpoint requires developer
messages. Known native OpenAI/Codex reasoning defaults remain intact.

Older readers cannot preserve the new `SignatureOnly` absent-text distinction.
Keep updated readers on histories that need signed absent-text replay. Image
budgeting requires canonical value messages and blocks when enabled, and its
unchanged nested content remains shared and must be treated as immutable.

`InheritEnv: false` limits a managed MCP child's environment; it does not create
a filesystem or network sandbox. `AllowUnauthenticated` permits an empty resolved
key but does not suppress configured credentials or authorize an endpoint.

Requires Go 1.26.2 or newer. No third-party dependencies changed since v0.23.0.
