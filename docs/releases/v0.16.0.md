Native skill catalogs and immutable embedded skill bundles.

## Changes

- Add opt-in agent/skills for explicit trusted directories: strict SKILL.md metadata, deterministic diagnostics, metadata-only prompt catalogs and bounded on-demand resource reads.
- Add NewFS and immutable FSCatalog for compile-time embed.FS bundles. Construction snapshots bounded text and closes handles; later reads do not access the source filesystem.
- Keep core agent loop unchanged. Skills provide guidance, not permissions. No runtime installation, network access, shell/Python execution, tenant policy or JZ-specific logic.

## Upgrade notes

- Version constant advances from 0.15.0 to 0.16.0 for the new additive API.
- Add gopkg.in/yaml.v3 v3.0.1. No database migration.
- Disk roots must be explicitly configured and trusted; catalogs are not a sandbox against hostile local writers. Application version labels are metadata, not integrity or authorization claims.
- Hosts remain responsible for authorization, prompt selection, resource limits and execution policy.

## Validation

Focused Linux Go 1.26.5 race tests (three repetitions) and vet for agent/skills and agent passed, with independent review of reload cleanup and immutable FS lifecycle. Windows amd64 skill tests cross-compiled but were not executed. Broader agent/toolset validation was blocked by missing offline cached dependencies; full repository regression and Windows/macOS runtime validation are not claimed.
