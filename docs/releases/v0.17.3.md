# v0.17.3

## Tool arguments

Completed tool calls expose the original JSON argument text in
`ToolCall.RawArguments` when the provider supplies it. Consumers that need
exact numeric IDs or duplicate-key validation can parse this text before
executing a tool. The existing `Arguments` map remains available to callers.
JSON conversation history omits the raw field.

Go callers using an unkeyed `ToolCall` literal must switch to named fields
when upgrading. Source builds require Go 1.26.2 or newer.

## Earlier changes included since v0.17.2

This tag also includes the provider HTTP response-body and agent/session
changes already merged on master, including durable input hooks, admission
receipts, cancellation handling, and terminal error propagation.
