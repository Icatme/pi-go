MIT licensing, clearer documentation, and packaged CLI downloads for the 0.17 series.

## Changes since v0.17.0

- Add the MIT license for pi-go and retain the original Pi AI copyright notice.
- Reorganize the README around installation, a complete quick start, CLI usage,
  packages and examples. Move detailed model, provider, quota and development
  guidance into focused documents with a shared index.
- Update the package version and examples module requirement to v0.17.1.

## Included in the 0.17 series

- Bound raw, parsed, normalized and before-hook tool arguments with
  `ToolDefinition.MaxArgumentBytes`, including direct, model and child calls.
- Prepare required/nullable tool schemas with `agent/strictschema`, preserving
  optional omission and exact scalar values through the default validator.
- Retain host context and current-run messages with
  `session.CompactionOptions.ProtectedTailMessages`.
- Inspect classified provider failures with `pigo.ProviderFailureOf`.
- Read skill frontmatter with one optional leading UTF-8 BOM, while preserving
  raw resources and body content. Use the maintained YAML organization parser.

See the [v0.17.0 notes](https://github.com/Icatme/pi-go/blob/v0.17.0/docs/releases/v0.17.0.md)
for API contracts and upgrade details. v0.17.1 adds no runtime API changes.
Go 1.26.2 or newer is required to build from source.

```sh
go get github.com/Icatme/pi-go@v0.17.1
go install github.com/Icatme/pi-go/cmd/pigo@v0.17.1
```

## Downloads

CLI archives cover Windows amd64, Linux amd64/arm64 and macOS amd64/arm64.
Each archive includes the MIT license and notices for its bundled dependencies.
`SHA256SUMS.txt` provides download integrity checks for all five archives.

## Validation

On Windows with Go 1.26.4 and `GOWORK=off`, the root and examples modules passed
`go test -mod=readonly -race ./... -count=1`, `go vet -mod=readonly ./...` and
`go mod verify`. Live-provider calls were disabled. Cross-built binaries do not
by themselves demonstrate execution on Linux or macOS.
