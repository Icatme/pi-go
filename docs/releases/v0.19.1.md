# v0.19.1

The OpenAI API provider now accepts `gpt-6.1-terra` on Responses. Use its exact
model ID for text, image input, streaming, or function calls. The model defaults
to medium reasoning. It accepts temperature and top-p sampling at effort
`none`. The catalog records the model's 1,050,000-token context window,
128,000-token output limit and short- and long-context prices.

This tag also includes the tool execution and filesystem fixes previously
merged in [#156](https://github.com/Icatme/pi-go/pull/156).

[OpenAI model reference](https://developers.openai.com/api/docs/models/gpt-6.1-terra)
